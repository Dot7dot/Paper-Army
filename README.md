# 紙上談兵 Paper Army

在真的紙上畫線，拍照後變成戰場地形；小兵從天而降，從左右兩邊出發自動戰鬥，地形的起伏決定勝負。

純靜態網頁（HTML + JS 模組），不需要建置，可以直接放在 GitHub Pages。

## 怎麼玩

1. **佈陣**：先決定兵要放在哪裡（只決定左右位置，開戰時從天而降）。
2. **畫地形**：在 A4 或任何淺色的紙上**橫放**，用深色的筆畫線，再用手機拍照（也可以從相簿選，或直接用手指畫）。
3. **確認地形**：會自動找出照片中的紙張，可以拖曳四角剪裁、調整「深色閾值」，下方即時顯示偵測到的地形與機關。
4. **開戰**：60 秒自動戰鬥，時間到時剩下比較多兵的一方獲勝（全滅對手會提早結束）。

### 模式

| 模式 | 說明 |
| --- | --- |
| 單人闖關 | 5 章 21 關，循序漸進解鎖角色與地形機關（見下方） |
| 雙人連線 | 兩人用自己的手機輸入同一組密碼連線；各自佈陣（最多 5 隻）、各自畫一張圖，兩張圖疊加成戰場 |
| 同一支手機對戰 | 玩家 1 佈陣、畫圖後把手機交給玩家 2，最後兩張圖疊加 |

## 單人闖關

### 新手引導（教學 UX 分支）

單人闖關現在有 **5 個連貫的教學階段**：進關前認識敵人與任務、點選兵種並部署、選擇拍照／相簿／手指畫地形、確認辨識預覽、觀察自動戰鬥。各階段會直接出現在遊戲操作畫面，以更大更粗的字呈現，佈陣數量與地形辨識狀況也會即時回饋。

- **第一關建議流程**：進入「初陣」→ 讀關卡目標 → 選劍士並點藍色半邊至少部署一隻 → 按「下一步：畫地形」→ 選「用手指畫」→ 畫一道平緩山丘 → 「完成」→ 確認預覽有線條 → 「開戰」。
- **拍照流程**：紙張橫放、深色筆畫線；照片調整畫面可旋轉、裁切與改變閾值；若完全沒有辨識到線條，單人模式的開戰按鈕會暫時停用，需調整或重拍。
- **進階關卡**：每關保留原本的新解鎖學習卡，並在佈陣、畫圖、確認等階段顯示本關專屬任務；失敗可直接重試，已獲得的星星不會消失。雙人模式仍沿用原流程。
- **開發檔案**：`js/solo-tutorial.js` 管理教學文案；`js/app.js` 管理階段提示、狀態回饋及防呆；`style.css` 管理大字、粗體、可點擊區與行動裝置排版。


每一關最多教一個新角色或新地形，第一次進入會跳出「學習卡」。還沒學到的地形機關不會觸發
（例如還沒到青苔那關，畫圓形只是一般的石頭）。每關三顆星：**勝利**、**完成任務**（通常就是用剛學到的東西）、**全員存活**。

| 章節 | 關卡 | 學到什麼 |
| --- | --- | --- |
| 第一章・紙上練兵 | 1～5 | 劍士、線條 → 弓手（高處）→ 重甲、陡坡 → 用陡坡擋敵人 → 考驗 |
| 第二章・圓滾滾的山丘 | 6～9 | 滾滾、圓滑弧面 → 青苔 → 草藥師 → 考驗 |
| 第三章・尖刺與盾牌 | 10～13 | 尖刺 → 盾衛 → 用盾擋箭 → 考驗 |
| 第四章・水窪與蘑菇 | 14～17 | 水窪 → 彈跳蘑菇 → 壁虎爬牆 → 考驗 |
| 第五章・爆破與決戰 | 18～21 | 爆破兵 → 用水窪讓炸彈熄火 → 城牆攻防 → 紙上決戰 |

關卡設定在 `js/levels.js`，新增關卡只要在 `RAW` 陣列加一筆（敵人、可派數量、提示、任務、教學內容），
可派出的角色與開放的地形會依順序自動累積。

## 兵種

| 兵種 | 特色 |
| --- | --- |
| 劍士 | 平衡型近戰，爬坡 50° |
| 滾滾 | 站在**圓滑弧面或青苔**上攻擊 ×2、速度 ×1.5 |
| 盾衛 | 碰到**尖角**就停下立起大盾：不怕尖刺、受傷 -70%、擋住敵人與箭 |
| 重甲 | 血厚攻擊高，但**坡度超過 25° 就走不上去** |
| 弓手 | 遠程；站得比敵人高，射程與傷害提升；箭會被地形擋住；喜歡待在高處 |
| 壁虎 | 可以**爬垂直的牆**，速度快、比較脆 |
| 草藥師 | 治療附近隊友，站在青苔上治療量加倍 |
| 爆破兵 | 拋物線丟炸彈越過障礙，爆炸會**炸開地形**；炸彈掉進水裡會熄火 |

## 地形機關

| 畫什麼 | 變成什麼 |
| --- | --- |
| 線條 | 地面／平台。線碰到紙的下緣或左右邊、或是封閉圖形，下面／裡面會填滿成實心的山 |
| 圓形 | 上面長**青苔**，站上去每秒回血 |
| 往上的尖角 | 尖角和兩側陡坡長出**尖刺**，碰到會受傷 |
| 碗狀凹槽 | 積**水**，走進去變慢，炸彈熄火 |
| 塗滿的小圓點 | **彈跳蘑菇**，把兵彈上天 |
| 彎彎的弧面 | 圓滑面（金色小點），滾滾的主場 |
| 陡坡、牆 | 爬坡能力不夠的兵會被擋住；從高處掉下會摔傷 |

## 線條偵測原理

沿用 [Draft Collective](https://github.com/Dot7dot/Draft-Collective) 的線稿提取（`lineDiff` / `lineAlpha`）：
每個像素跟周圍區域的平均亮度比較，「比周圍暗多少」超過**深色閾值**就算是線條，
所以紙張上的陰影、光線不均不會被當成地形。接著：

1. 照片拉伸成 A4 橫向比例，縮成 300×212 的格子，每格有足夠的深色像素就算線條；去掉小雜點和貼著照片邊緣的紙邊。
2. 線條加粗一格補縫，從天空往下灌「空氣」，灌不到的地方（被線圍住、或線條和地面之間）變成實心。
3. 分析形狀：連通區域的半徑變化很小 → 圓形；塗滿的小塊 → 圓點；兩側都很陡的頂點 → 尖角；
   像下雨一樣計算會積水的凹槽；表面曲率平順變化 → 圓滑面。

## 雙人連線

使用 [PeerJS](https://peerjs.com/)（WebRTC 點對點）與它的免費配對伺服器，不需要自己架伺服器。
建立房間的人（藍隊）負責跑戰鬥模擬，並把畫面同步給對方（紅隊）。
少數網路環境（例如部分公司網路、行動網路的對稱型 NAT）可能無法直接連線。

## 發布到 GitHub Pages

1. 把這個分支合併到 `main`
2. GitHub 倉庫 → **Settings → Pages → Source** 選 **GitHub Actions**
3. 推送後 `.github/workflows/pages.yml` 會自動部署，網址類似 `https://<帳號>.github.io/Paper-Army/`

（也可以在 Source 選 **Deploy from a branch** 直接發布 `main` 的根目錄。）

相機需要 HTTPS，GitHub Pages 已經是 HTTPS。

## 本地開發

```sh
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 檔案

```

style.css            樣式
js/app.js            畫面流程（首頁、闖關、佈陣、拍照、調整、戰鬥、連線）

js/render.js         繪圖（紙張、地形、士兵、特效）
js/net.js            PeerJS 連線
icons/               App 圖示
```
